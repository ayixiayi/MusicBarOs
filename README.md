# 关于本项目
## 发端与结束
做这个项目主要是因为大一工程学导论课让从头到尾做一个完整的项目，，，

感觉做得纯一坨

软件借助各种AI工具与github写了一个残血网易云，加了一些个性化需求

硬件找到了大佬发布的现成模型，结果和我的想象略有出入，只好重新手搓一个，感觉会有各种意想不到的问题，因为尺寸完全是一拍脑门定的

从十一月做到十二月，完全燃尽了。

不论如何，这个项目在我上传到github时基本可以宣告完成了，在这里非常感谢和我一起完成这个项目的四位同学。

## 个人的想法
说实话我真的很想做平泽进式的激光竖琴，已经做这个梦好久了。然而仔细一想，校准光路麻烦的要死，金属加工一窍不通，键盘映射我倒是学会了，不过前面两个技能学起来应该真的需要个人工作室吧，只能日后再圆梦了

还有我真的非常不喜欢华语流行，如果可以的话真想都删掉啊，如果这个项目是我一个人做我不会放一首中文歌。不过还是要尊重别人的劳动成果吧，毕竟还要评分，我不在乎有的是人在乎。

哦对了，我还想说为什么会有人喜欢手搓出来的，完全是为了这门课而生的玩票性质的成果？老师竟然觉得我这个产品太成熟了，看上去平平无奇？出离愤怒了。

一个不完美的产品和垃圾没有区别。

为了践行我的这句话，我给我的软件买了服务器做后端，虽然在安卓上演示，但我还是写了windows版，虽然我还有很多遗憾，比如回=回式的旋转播放界面、一键双向绑定、后台通知卡片（这个写起来比我想象中难得多得多，完全无法实现），但是我想我的产品，至少软件上，一定是最接近完美的，也是最接近产业环境，可以真正投入使用的。只要稍微翻一翻各家手机的开发文档，后端换个并发量更大的服务器就行了。所以结果对我来讲其实无所谓，至少我对完全由我自己开发的产品很有信心。
